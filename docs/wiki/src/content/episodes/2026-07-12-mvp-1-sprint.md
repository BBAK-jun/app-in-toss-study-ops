## 목표

PRD(`docs/PRD-StudyOps-Bot.md`)에서 정의한 MVP 1차 범위 8개 기능을 7/12~7/15 기간 내에 구현한다. 8/5 데모까지 작동하는 end-to-end 플로우를 확보하는 것이 1차 목표.

## 구현 범위

| # | 기능 | 상태 | 비고 |
|---|---|---|---|
| 1 | Toss OAuth2 인증 (dev/live 분기) | ✅ | dev 모드: `dev-<userKey>` 파싱 |
| 2 | 스터디 CRUD + 참여자/회차 서브 리소스 | ✅ | Hono 라우트 그룹 |
| 3 | 회차별 제출 현황 (제출률 자동 계산) | ✅ | `GET /rounds/:id/status` 핵심 |
| 4 | 제출 링크 등록 (UNIQUE 제약) | ✅ | 회차당 1인 1제출 |
| 5 | 리마인드 문구 자동 생성 | ✅ | 미제출자 멘션 포함 |
| 6 | Discord Webhook 발송 | ✅ | Embed + mentions |
| 7 | 6개 화면 (로그인→스터디→회차→제출→리마인드) | ✅ | TDS Mobile + React Router v6 |
| 8 | D1 마이그레이션 + Wrangler 배포 파이프라인 | ✅ | `--local` 우선 정책 |

## 기술 스택 (최종)

- **서버**: Hono on Cloudflare Workers + Drizzle ORM + D1 (SQLite)
- **클라이언트**: Vite + React 18 + TypeScript + `@toss/tds-mobile` + `@apps-in-toss/web-framework`
- **인증**: Toss OAuth2 (HS256 JWT, 7일 만료, sessionStorage)
- **공유 타입**: `packages/shared` (npm workspaces 모노레포)
